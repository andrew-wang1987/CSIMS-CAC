# CSIMS
CSIMS (Crisis Simulations) is an web app created to optimize mental health crisis intervention developed for the Congressional App Challenge in the FL-27 district. Utilizing a complex machine learning algorithm created in Pytorch, it provides data-driven crisis response recommendations based on patterns identified in historical data across the United States.
